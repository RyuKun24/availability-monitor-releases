# Availability Monitor - Development Guidelines

## TL;DR: Release Checklist

Before a feature is considered "done":

- [ ] Code committed and pushed to feature branch
- [ ] `pyproject.toml` version = `electron/package.json` version
- [ ] Tag created: `git tag vX.Y.Z`
- [ ] Tag pushed: `git push origin feature/name --tags`
- [ ] GitHub Actions PASSED (not failed)
- [ ] Release appears on GitHub with .exe downloads
- [ ] Merged to main with same tag

## Branch Strategy

```
main (stable releases)
- v1.0.0 (stable tag)
- v0.2.0
- v0.1.0

feature/electron-launcher (development)
- v0.1.2 (successful build)
- v0.1.1 (failed build - fixed)
- v0.1.0 (initial attempt - fixed)
```

## Workflow

### 1. Feature Development
```bash
# Create feature branch
git checkout -b feature/my-feature

# Work and commit
git add .
git commit -m "feat: description"
git push origin feature/my-feature
```

### 2. Prepare Release
```bash
# Update version in BOTH files
# pyproject.toml: version = "0.1.2"
# electron/package.json: "version": "0.1.2"

git add pyproject.toml electron/package.json
git commit -m "bump: version 0.1.2"
```

### 3. Create Tag & Trigger Build
```bash
git tag v0.1.2
git push origin feature/my-feature --tags
```

### 4. Monitor Build
- Open Actions tab on GitHub
- Wait for workflow to complete
- Check for ✅ SUCCESS or ❌ FAILED

### 5. Verify Release
- Visit Releases page
- Download and test .exe files
- If failed: bump to v0.1.3 and retry

### 6. Merge to Main (when ready)
```bash
git checkout main
git merge feature/my-feature
git tag v0.1.2
git push origin main --tags
```

## Version Sync is CRITICAL

These MUST match exactly:
- `pyproject.toml` → `version = "X.Y.Z"`
- `electron/package.json` → `"version": "X.Y.Z"`
- Git tag → `vX.Y.Z`

Mismatch = Build failure ❌

## Don't Forget

[OK] Always create feature branches (never commit to main)
[OK] Always sync versions before tagging
[OK] Always wait for GitHub Actions to finish
[OK] Always verify release files exist before considering done
[OK] Always test .exe on clean system (or ask spouse to test)
